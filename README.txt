Dota Drafter & Counter-Pick PWA
=================================

Как запустить на Android:

ВАРИАНТ 1 (Самый простой — без установки доп. программ):
1. Распакуйте архив на телефоне или залейте файлы (index.html, manifest.json, sw.js) на бесплатный хостинг (GitHub Pages, Vercel, Netlify, Replit).
2. Откройте ссылку в Chrome на смартфоне.
3. Нажмите в меню Chrome (три точки) -> "Установить приложение" (или "Добавить на главный экран").
4. Приложение появится на рабочем столе как отдельная иконка без адресной строки браузера и будет работать даже офлайн!

ВАРИАНТ 2 (Собрать настоящий APK через WebAPK / PWA2APK):
- Воспользуйтесь сервисом https://pwabuilder.com (официальный проект от Microsoft).
- Вставьте ссылку на развернутый сайт и нажмите "Generate Android Package (APK)".
- Скачайте и установите APK на свой телефон.

ВАРИАНТ 3 (Локально через Termux):
- В Termux:
  pkg install nodejs
  npx serve .
- Откройте http://localhost:3000 в мобильном браузере.
